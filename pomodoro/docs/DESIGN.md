# Figma 디자인 후보 검토

검토 상태: **사용자 선택 대기**. 실제 앱의 현재 화면은 기능 검증용 임시안입니다.

파일: https://www.figma.com/design/vkjcUlrnlPUmcJa8SCzvGt

| 안 | Figma 프레임 | 특징 |
|---|---|---|
| A / Quiet Focus | 5:131 | 큰 중앙 타이머 + 오른쪽 할 일/오늘 통계. V1 추천 |
| B / Study Ledger | 5:191 | 프로젝트 탐색 + 계획표 + 주간 요약. 학습 시간 관리 중심 |
| C / Personal Studio | 5:262 | 어두운 넓은 작업실 + 세션 타임라인. Focus Room 확장 고려 |

각 안은 선택 가능한 방향을 보여주는 새로 만든 편집 가능한 Figma 시안입니다. 이미 만들어진 커뮤니티 템플릿을 복제한 것은 아닙니다. Figma Simple Design System의 버튼 인스턴스를 활용했습니다. 시안 속 과목명, 시간, 회고는 예시 데이터입니다.

시안은 데스크톱 주 화면입니다. 선택 후 모바일, 회원가입, 통계, 회고, 설정과 빈 상태/오류/실행 중 상태까지 일관되게 확장합니다. C안도 이번 V1에 게임 보상이나 공간 꾸미기를 추가한다는 의미가 아닙니다.
