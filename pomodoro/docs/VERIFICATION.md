## 실제 Chrome 확인

로컬 테스트 계정으로 회원가입 → 프로젝트 생성 → 할 일 생성 → 집중 시작 → 일시정지 → 새로고침 후 23:29 일시정지 복원 → 중단 → 집중도 4/5 및 메모 저장 → 통계에 1분 31초/완료 0회/중단 1회 반영 → 주간 회고 저장을 확인했습니다.

테스트 데이터는 `UI 검증 계정`에만 있습니다. 사용자 실제 계정과 별개입니다. 브라우저에서 로그아웃 후 본인의 계정을 만들면 빈 작업실에서 시작합니다.

브라우저 알림은 OS 권한 설정을 임의 변경하지 않았으므로 실제 알림 전달까지 확인하지 않았습니다. 모바일 레이아웃과 접근성은 최종 디자인 선택 후 추가 검증합니다. 공개 배포, 이메일 확인, 비밀번호 재설정, 데이터 가져오기는 미구현입니다.

## 디자인

Figma의 A/B/C 세 후보를 1280px 화면으로 렌더해 잘림과 겹침을 확인했습니다. 본문은 Noto Sans KR, 큰 숫자는 Inter를 사용합니다. 시안은 사용자 선택을 기다리고 있으며 현재 코드의 임시 UI를 대체하지 않았습니다.
